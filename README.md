# Fija Móvil

Build a mobile-first web app for the traditional Venezuelan equestrian betting game 'Tabla Fija' (Eastern Venezuela style). Features: 1. Banquero (Admin) panel to manually create races (track/hipódromo, race number, horses list), set fixed odds/payout multipliers per horse, register player tickets, close betting, declare winner ('cruza la raya'), and calculate payouts and net balance. 2. Jugador (Player) mobile view to see the live board with all horses and their fixed table multipliers, a quick payout calculator, and ticket status lookup. Designed mobile-first with Venezuelan turf aesthetic.
